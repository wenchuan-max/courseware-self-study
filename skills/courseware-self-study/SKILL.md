# 课件转互动自学网站

把课件变成能操作、能理解、能自测的学习路径。保留原始证据，压缩无助于理解的文字。沿用用户的语言、存放位置和已确认的设计；既有网站先检查再修改，不以模板覆盖。

## 1. 盘点并建立课件证据

- 检查输入文件、已有项目、运行入口和未完成事项。按实际文件建立清单；不要把“15 章”误当成“恰好 15 个文件”，补充课件也要纳入。
- 原课件只读。优先以导出的 PDF 提取整页图片和页码，以 PPTX 补充备注、动画分步和可编辑文本。PDF 无文本层时使用可用 OCR，并抽样核对公式、上下标和图注。提取不到的内容明确记录，不能用章节标题冒充覆盖。
- 阅读 [内容结构与数据接口](references/content-schema.md)。复用 scripts/courseware.py 的 init、prepare 和 build；现有项目不必迁移数据接口，保持其兼容性。
- prepare 完整处理 PDF，另提取 PPTX 正文和备注。PPTX 图片不是整页渲染；如需整页图，使用环境中可用的演示文稿工具或可靠转换器导出 PDF，再运行 prepare。

## 2. 按学习任务组织，而不是搬运页面

建立“课程 → 主题 → 可选知识点”。每个主题包含来源范围内的全部关键知识点，让学习者选择拆解哪个点；数量由课件决定，不给每个主题强塞相同数量的卡片。

每个点包含：一个具体问题、逐步推理、结论、原页依据。概览解释知识点之间的关系；完整课件页仍可查看、放大和定位。原页分配完整，只证明页码有归属，还要人工对照原页审查概念、方法、例题、条件和图示是否真正被讲解。

用户只要求 demo 时选一个有代表性的学习闭环；用户已要求全量扩展时直接继续，不重复征求是否扩展。大课程按来源范围分批生成，统一稳定 ID 和接口，再跨批审查。只有获得授权时才委派子任务。

## 3. 让每个实验与当前知识点真正相关

设计“先预测 → 改条件 → 看过程 → 比较结果 → 解释原因”。能计算的任务使用公式和参数；概念、历史、方法类任务可用证据排序、过程标注、条件比较和推理分支。

- 通过明确的知识点 ID / modelId 绑定实验。禁止根据标题关键词猜测模型，或在缺失配置时悄悄复用上一主题的实验。
- 切换章节、主题或知识点时同步更新实验标题、条件、图、结论及当前选择，清理上一实例的事件和定时器。
- 对照案例必须有实质不同的条件和推理。结果相同也可能具有教学价值，不能只凭结果重复判为无效。
- 模板的 compare 只是通用起点。为课程中关键机制添加专门模型和可解释的可视化，不把所有主题都做成同一种点击卡片。
- 原课件图用于准确溯源，网页内图用于解释机制。公式、箭头、坐标、颜色含义要与文字和计算一致。避开仅起装饰作用的大图。

## 4. 题库与内容正确性

题目覆盖概念辨析、条件判断、读图、计算和综合应用；各主题可筛选，回答后给推理和常见误区。开放题提供评分点和自评，不能假装自动判分。

用户要求考研真题时，先阅读 [真题与内容审查](references/review-and-exams.md)。通过可核验的真实试卷补充题库，准确区分原题、改编、同知识点拓展和未核验材料。不得给原创题编造学校、年份和题号。

审查课件依据、概念边界、因果链和公式条件，独立复算关键数值。发现原课件错误时保留原页，在相关讲解处做简短更正；同步修改概览、步骤、实验、答案和图。不能承诺“保证零错误”，应交付实际审查范围和剩余限制，避免把这种审查说明堆进学生主界面。

## 5. 验收并交付

阅读 [浏览器验收与离线交付](references/qa-and-delivery.md)。数据/DOM 检查、数值复算和真实浏览器检查各自提供不同证据，不相互冒充。

检验跨章节切换、每个知识点实验绑定、错题、进度、刷新恢复、原页图、桌面和窄屏。测试进度与学习进度分离；折叠卡片不撤销已阅读状态。先按内容范围验证，再按交互状态抽样；若用户要求全量审查，覆盖所有数据并实际检查代表性机制。

离线优先采用本地经典脚本加载，不依赖 fetch、模块跨域或 CDN。已有构建系统可保留，但分享产物必须独立运行。打包前检查相对路径、资源版本、ZIP 完整性，移除开发依赖与个人进度。说明解压后打开的准确文件名；不得擅自发布用户课件。

## 工具入口

用环境中发现的 Python 运行本技能目录下的脚本，不硬编码某台电脑的解释器路径。新站点的快捷流程：

~~~text
python scripts/courseware.py init --output <网站目录> --title <课程名>
python scripts/courseware.py prepare --input <课件目录> --project <网站目录>
# 对照来源编写 content/course.json，并扩展 models.js 中的专门实验
python scripts/courseware.py build --project <网站目录>
python scripts/courseware.py validate --project <网站目录>
python scripts/courseware.py serve --project <网站目录> --port 0
python scripts/courseware.py pack --project <网站目录> --zip <分享包.zip>
~~~

PDF 渲染需要 pypdfium2 和 Pillow。除这些库外脚本使用 Python 标准库；站点运行不需要 Python、Node 或安装依赖。脚本验证结构和引用，不能代替教学内容审查。prepare 的报告会列出未渲染输入；未解决时不要宣称全量交付。

参考本次对话中验证过的完整流程、修正和取舍时，按需读取 [遗传学项目复盘](references/lessons-from-genetics.md)。其中数字、学科结论和界面风格仅为案例，不是其他课程的配额或固定要求。
