# 浏览器验收与离线交付

## 三种检查分开记录

- **结构 / DOM**：ID、引用、题目选项、模型绑定、切换后的内容、全部图路径、筛选和学习进度。脚本遍历可覆盖所有数据，不能因此宣称所有页面已做视觉验收。
- **独立数值**：关键公式、原始数据和边界值，使用独立实现或手算复核。仅比较同一函数的两个调用没有独立性。
- **真实浏览器**：桌面及实际窄屏视口、图片放大、抽屉/选择器、长标题、反馈、跨主题状态、原页浏览和离线打开。依据场景选样，不把几张截图当成完整数据审查。

模板 ?qa=1 使用独立 localStorage 命名空间。测试完成不清空用户正式学习记录。阅读进度、卡片展开、答题、错题分别持久化；收起卡片不会撤销已读。

切换主题检查实验标题、变量、因果链、结果一起变化。无模型时显示缺失配置，不得保留旧图或自动套用不相关模型。检查不同行为状态：初始、操作后、换主题、返回、刷新、空结果和缺失资源。

## 浏览器实际操作

用当前环境支持的浏览器工具。先读工具文档，遵守访问边界；文件入口不支持时可用本地 127.0.0.1 服务检查，不绕过工具限制。serve --port 0 可选空闲端口；仅关闭自己创建且确认身份的服务。

截图前确认活动标签、实际 innerWidth 和截取区域。切换工具辅助标签可能改变视口；桌面截图的左侧裁剪不能当作手机布局。看截图的真实尺寸和内容，发现不符就重设视口重新截图。记录桌面/手机实际宽度，检查横向溢出。

浏览器工具暂不可用时，保留已完成的结构和数值结果，并准确说明视觉检查未完成。后续恢复后补做并更新记录，不继续沿用过时的“未检查”。

## 缓存与资源

当数据接口或样式变化时，更新脚本和样式的版本参数，避免页面混用新数据与旧缓存。依赖检查使用 URL 解析器移除查询和片段后定位磁盘文件，不能把 style.css?v=... 当作真实文件名。

离线站点用相对路径、本地字体/图片、经典脚本和打包数据。file:// 下验证入口，不假设本地服务可用就意味着直接打开也能用。不要依赖 CDN、运行时 fetch、构建服务器或只有作者电脑上才存在的绝对路径。

## 打包

明确白名单：HTML、样式、脚本、作者数据、原页图片、被引用原课件及必要入口/说明。排除 node_modules、临时 QA、缓存、日志、密钥和个人进度。完整包含来源是为了用户已要求的本地分享，不代表获得公开发布课件的授权。

pack 会先检查结构、资源和覆盖，再生成 ZIP、CRC 测试与简要 SHA256；这些检查不证明科学结论正确。full 范围内出现缺失渲染或覆盖错误要修复后交付，不用“已打包”掩盖。

Windows 分享包提供 打开网页.cmd，解压后可双击；index.html 也可直接打开。交付明确说“先完整解压，再双击什么”，不要让接收者在 ZIP 内预览。模板生成的使用说明属于网站产物，不是技能安装说明。

## Windows 制作注意点

- 中文文本显式写 UTF-8。不要把长正文塞进容易触发变量替换的命令；用字面量文本或专用文件工具。单次 Windows 命令不要接近约 32K 字符上限。
- 源文件只读；输出和测试目录与来源分开。清理前确认绝对路径范围。
- 运行时从环境发现，不硬编码作者的 Python/Node 路径到分享产物。
- 新增模型或依赖时检查离线产物的完整闭包；不要把测试运行时一并装进分享包。
