# 互动自学网站的设计经验

这些规则适用于不同学科，不绑定某门课程、真实用户、文件数量或既有对话。

## 建立完整学习闭环

先确定一个学习者能完成的任务：从具体问题出发，作出预测，操作有意义的条件，解释过程，再用题目检验理解。demo 展示这个闭环；全量扩展按来源范围落实知识覆盖，而不是复制同一种卡片。

按“课程 → 主题 → 可选择的知识点”组织。主题概览解释知识点之间的关系；知识点提供逐步推理、结论和原页依据。章节数量不等于文件数量，封面、补充文件、图注、公式和备注都要盘点。

原页有归属只证明页码覆盖，不代表知识已被讲解。对照原页逐项核查概念、条件、方法、例题和图示，避免把课件目录或整页图片当成完成教学。

## 实验必须对应当前知识点

用明确 ID 注册和绑定模型，切换时更新标题、条件、图、机制和结论，并清理旧监听器。缺失模型直接显示缺失，不能回退到不相关模型。

计算主题用参数和数值结果，机制主题用过程和因果链，历史或方法主题用证据排序、标注和条件判断。对照条件需要实质差异；不同条件得到相同结果也可能有教学价值。

先预测再展开解释，变量应有学科含义。保留必要条件，压缩重复标签、装饰性大图和无助于判断的说明。

## 进度与自测

阅读状态和展开状态分开。标记已读不打断当前操作；折叠不撤销阅读记录。测试使用独立存储，避免污染真实学习进度。稳定 ID 不随匿名来源标题变化，原有记录继续关联正确知识点。

选择题解释答案和误区；开放题给评分点并自评。真题改编必须给齐独立作答所需的条件和图例；原题、改编、拓展和未核验材料分开标记。

## 内容与网页分别验收

来源核对、概念审查、独立数值复算、结构检查和真实浏览器检查提供不同证据。发现问题时同步修正步骤、概览、案例、图和答案，不能只改最终数字。

手机验收确认实际视口宽度、长标题、菜单、状态标签和图片放大。截图的左侧裁剪不能代替手机布局检查。资源查询参数用 URL 解析后再定位文件，更新版本以避免新旧缓存混用。

## 编辑工程与分享产物分开

备课工程可保留完整原课件和备注，以支持准确讲解和后续编辑。工程目录不能直接当成公开网站目录。

默认分享仅导出教学引用所选页面、公开教学字段和明确列出的网页资源。原页图与选定页 PDF 保留可视化和溯源功能；原文件、备注、文件名、输入路径和辅助笔记留在本地工程。

显式本地归档保留编辑资料；公开交付只使用分享 ZIP 的解压目录。实际姓名、学校、学号、联系方式、私人路径或独特用户经历不写进可复用的技能、示例和发布说明。
