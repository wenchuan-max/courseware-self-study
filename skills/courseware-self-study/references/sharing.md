# 分享边界与兼容性

## 默认分享

build 与 pack 默认使用 --mode share。网页数据由公开字段重新生成，不直接复制完整作者 JSON；pack 也会重新生成数据，防止先前 archive 构建进入分享包。

页面范围取所有 topic.refs 和 point.refs 的并集，同时受 scope.sourceIds 限制。引用未选择的来源、或同一页同时引用和排除时直接报错，不能静默删除知识点。excludedPages 仅用于来源覆盖记录，不公开排除理由。

仅导出所选页面的文本和图像。来源默认使用“课件 1”等中性标题；不带原文件名、relativeInput、内容哈希和审查笔记。指定标题可使用：

~~~json
{
  "share": {
    "sourceTitles": {"来源ID": "公开章节名称"},
    "files": ["assets/diagram.svg", "extra-model.js"]
  }
}
~~~

share.files 是额外网页资源的明确清单，可用图片、字体、音视频、样式和经典脚本；不允许加入 reference、content、sources、pages、handouts、隐藏路径、符号链接或任意文档。自定义模型使用的图片、脚本和样式也在此声明。依赖未列入时，打包报错而不是扩大收集范围。

主模板脚本、样式和数据自动纳入，不必重复声明。知识点、题目、案例、纠正文字和自定义模型参数是公开教学配置，其中不能放私人笔记或凭据。额外模型代码仍需检查网络请求。

## 原页和来源 PDF

分享图像重新编码以丢弃 EXIF/XMP 等附加信息，保持解码后的像素一致。每个来源只将选定页面生成图像式 PDF；“打开课件”打开这份选定页 PDF，不包含原文件的隐藏文本、作者字段或演讲者备注。

原物理页号保留在引用和原页查看器中。不连续的选页按已导出页翻页，不要求分享中间页面。PDF 内部页序可能与原物理页号不同。

可见在图片中的姓名、学号、联系方式不会因清除文件元信息而消失。交付前查看选页，必要时在分享副本上遮盖这些区域并复核，不改动原始课件。自动隐私筛选不能替代可见内容的判断。

## 本地完整归档

~~~text
python scripts/courseware.py pack --project <工程目录> --zip <本地归档.zip> --mode archive
~~~

archive 明确保留原文件、全部已导入原页、来源清单、作者数据和 PPTX 正文/备注，以便继续编辑。它不递归收集额外笔记或隐藏目录。该包用于本地保存，不能当默认公开分享包。

需要在本地网页打开原文件时，可显式 build --mode archive。随后 pack --mode share 会重新生成裁剪后的数据，不沿用完整构建。

## 发布与更新

只公开分享 ZIP 的解压目录，不上传备课工程。分享 ZIP 使用固定根目录 self-study，文件时间与 ZIP 属性标准化，避免复制本机目录名和文件附加信息。打开入口仍为 打开网页.cmd 或 index.html。

既有工程只需更新运行工具与模板、保持课程和知识点 ID 稳定。不要覆盖已编写的作者数据或清除浏览器记录。采用其他数据接口的现有网站，应实现等价的分享过滤，不强制迁移。

制作可复用技能的公开文档时使用通用案例，不附真实课程规模、对话过程、身份线索或本机路径。最新版本清理不等于旧提交和旧下载包已被清理；历史清理是另一个明确操作，不能隐瞒其仍然存在。
