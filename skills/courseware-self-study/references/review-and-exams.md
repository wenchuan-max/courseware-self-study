# 真题来源与内容审查

## 先核验出处，再写题

用户要求历年真题时，搜索真实试卷。优先学校/研究院招生网站的原始试卷 PDF；其次可追溯的原卷扫描件。搜索摘要、培训网站的无来源“真题”、考试大纲都不能证明题目出自某年真卷。

核验学校、年份、考试名称/代码、题号和原卷页码。年份取试卷内容，不取网页上传年份。保存能定位到试卷的 URL；失效链接或只有二手转述时记录核验缺口。

原文、简化改编和同知识点拓展分开标注。改变数据、选项、情境或增加条件的题目不能标“原题”。没有官方答案时，答案为独立推导，不伪称官方解析。改编必须自足，重新给出亲本相位、初始条件、数据、图例；避免“根据上题”而上题不在页面。

增加题目应增加知识和认知层次覆盖；不要仅换数字凑数量。每题能回到相应知识点，解答说明关键条件与错误选项的误区。

## 三层审查

1. **来源层**：将 topic / point 与原页逐项对照，核查定义、图注、步骤、例题及未覆盖内容。图片可读但文本提取遗漏的公式必须人工补入。
2. **语义层**：核查必要条件、量纲、定义域、因果方向、例外和机制边界。简化模型应在对应操作旁说明适用条件；不要用全站冗长免责声明代替条件。
3. **独立数值层**：从原始数据重算，避免只用网页相同函数自证。检查边界、零分母、符号、舍入与概率和。科学公式按当前任务需要查阅可靠原始教材、论文或官方资料。

有独立审查资源且已获授权时，给审查者原始资料和待审内容，让其自行推导。不能用“另一人看过”代替可追溯的发现、修改和复算记录。

发现问题时检查所有呈现位置：概览、知识点步骤、案例因果链、数值结果、图、题目答案和最终压缩包。只改最终数字会留下互相矛盾的解释。

## 本次遗传学工作中有价值的审查类型

以下是案例，不作为其他学科的硬规则：

- 原课件可能本身出错：cohesin / condensin 混用、单倍剂量不足解释、lncRNA 长度阈值等采用注释层更正，原页保留。
- 统计量需要尺度一致：原始分离位点数 S 与群体参数估计值不能直接混用；Watterson 估计使用 S / a_n。
- 有符号量的“降低”容易误导：连锁不平衡 D < 0 时趋近 0 是数值上升，而绝对值衰减；D = 0 不能单独证明不存在基因流。
- 方向性语言也要核查：同一起点的两个复制叉向相反方向推进。
- 计算应从原数据复算：271 / 4197 ≈ 6.45699%，精度决定显示 6.46% 或 6.5%；不能照抄错误舍入。
- 上位性判断依赖模型：简单线性生物合成、完全功能丧失等假设不能推广为一切调控网络的上下游关系。
- 极端尾概率有数值稳定性问题：不能只验日常输入，避免 1 − erf 一类相消导致错误。
- 期望个体数不等于保证出现的最小样本量；零分母场景应显示未定义。

## 审查输出

在项目 reference/ 中留机器可读统计和简短审查记录：来源范围、内容范围、复算方法、已修正项、尚未核验项、浏览器证据路径。可对已实际完成的审查标记 reviewed，但不作零错误保证。学生页面只呈现理解当前知识所需的条件、更正和出处。
